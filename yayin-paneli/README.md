# Sürüm 1 — tek dosyalık web paneli (arşiv)

`index.html` sürüm 1'in tek dosyalık arayüzüdür (Claude Artifact olarak yayınlanmıştı,
verileri artifact veritabanında tutar). Sürüm 2 ile birlikte yerini
`yayin-paneli-python/web/` altındaki PWA arayüzüne bıraktı.

Sürüm 2'de olup burada olmayanlar: kaynak bazlı çeyreklik (JCR / CiteScore), kaynak
bazlı h-indeksi, saat başı otomatik toplama, onay kuyruğu, çevrimdışı çalışma.

OpenAlex ve SCImago SJR bağımlılıkları sürüm 2'de kaldırıldığı için bu dosya artık
geliştirilmiyor; eski bağlantıların çalışmaya devam etmesi için saklanıyor.
